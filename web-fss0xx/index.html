احترام خصوصية المستخدمين

📌

المعلومات التي قد يتم جمعها

قد يتم جمع بعض المعلومات الضرورية لتشغيل الخدمات، مثل:

  • معرف Telegram (Telegram ID).
  • اسم المستخدم عند توفره.
  • بيانات البوتات التي يضيفها المستخدم إلى المنصة.
  • الملفات أو الأكواد التي يرفعها المستخدم لغرض الاستضافة.
  • معلومات تقنية أساسية ضرورية لتشغيل الخدمة وحمايتها.
🔐

استخدام المعلومات

يتم استخدام المعلومات فقط من أجل:

  • تشغيل وإدارة خدمات الاستضافة.
  • توفير خدمات البوتات للمستخدم.
  • تحسين أداء واستقرار المنصة.
  • حماية المنصة من الاستخدام غير المصرح به أو إساءة الاستخدام.
🚫

مشاركة البيانات

لا نقوم ببيع أو تأجير البيانات الشخصية للمستخدمين. وقد يتم الكشف عن معلومات عند الضرورة للامتثال للقوانين أو لحماية المنصة ومستخدميها.

🗑️

حذف البيانات

يمكن للمستخدم طلب حذف بياناته أو خدماته المستضافة وفقًا لإمكانيات المنصة وإجراءاتها.

حماية البيانات
